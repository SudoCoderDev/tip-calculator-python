# Tip Calculator

A simple Python tip calculator that calculates the amount each person should pay after adding a selected tip percentage.

## How It Works

The program asks the user for:

- The total bill
- The desired tip percentage
- The number of people splitting the bill

It then calculates the total bill including the tip and divides it equally among the people.
